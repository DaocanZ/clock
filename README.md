# 我的时钟 (My Clock)

一个模仿微软时钟（Windows Clock）的桌面倒计时任务应用，使用 **Python + PySide6 (Qt6)** 构建。可自由调整、可二次开发。

## 功能特性

- **任务清单**：新增 / 改名 / 删除任务，每项任务带独立的倒计时闹钟。
- **标记完成**：一键把任务标记为已完成（删除线 + 灰色 + 控件禁用），也可恢复；完成状态持久化。
- **倒计时**：每项任务可设置时长（默认 10 分钟），支持开始 / 暂停 / 继续 / 重置。
- **计时页**：选中任务后以醒目大字展示倒计时。
- **闹钟提醒**：倒计时结束时弹出置顶提醒"请完成任务"，并**循环播放铃声**。
- **自定义铃声**：可选择一个本地音频文件（wav / mp3 等）作为闹钟铃声，或恢复默认系统提示音。
- **进行中任务高亮**：正在倒计时的任务行高亮显示，一眼识别当前任务。
- **前置小窗（紧凑模式）**：仿微软时钟，主窗口与小窗**互斥切换**；小窗始终置顶、可自由缩放、字体随窗口大小自适应，显示大字倒计时 + 当前任务一行提醒。
- **数据持久化**：任务清单与铃声设置自动保存到本机，重启不丢失。
- **窗口自由缩放**：取消最小尺寸限制，可任意拉大缩小。

## 技术栈

- Python 3.10+
- PySide6（Qt6）

## 环境要求

- Windows（铃声播放部分用到系统 API；其余跨平台可用）
- Python 3 环境

## 安装与运行

首次使用，双击运行：

```
install.bat
```

之后每次启动，双击：

```
run.bat
```

或手动执行：

```bash
pip install -r requirements.txt
python main.py
```

> **注意**：若你的机器装有 Anaconda，系统 `python` 可能与 PySide6 存在 DLL 冲突。因此脚本会优先使用独立的 `.venv` 虚拟环境（基于非 Anaconda 的 Python 3.14）来运行。直接运行 `run.bat` 即可，无需手动处理。

## 使用说明

- **任务清单**标签页：输入任务名回车或点"＋ 添加任务"；每行可设时长（分/秒）、开始/暂停/重置、标记完成、删除。
- **计时**标签页：从下拉框选任务、设定时长，用大字倒计时开始/暂停/重置。
- 顶部工具栏 **`⤢ 切换小窗`**：切换到始终置顶的小窗（显示倒计时和当前任务）；小窗内 **`⌂ 回到主窗口`** 切回。
- 菜单 **设置**：选择闹钟铃声、恢复默认铃声、切换小窗模式、关于。

## 数据存储

- 任务清单与铃声设置自动保存在：
  `%APPDATA%\MyClock\MyClock\my_clock_data.json`

## 项目结构

```
clock/
├── main.py              # 程序入口
├── install.bat          # 首次安装脚本
├── run.bat              # 启动脚本
├── requirements.txt     # 依赖清单
└── app/
    ├── task.py          # 任务模型 / 倒计时逻辑 / 持久化
    ├── tasks_page.py    # 任务清单页（含完成标记）
    ├── timer_page.py    # 大字倒计时页
    ├── mini_window.py   # 前置小窗（紧凑模式）
    ├── alert.py         # 闹钟提醒对话框 + 铃声播放
    └── main_window.py   # 主窗口、工具栏与菜单
```
